調査システムPWA Prototype v0.11.2 変更点メモ

■ カメラ戻り時の初期化対策
- カメラ起動前に現在の案件状態を localStorage へ保存。
- app.html 再表示時に保存状態を復元。
- beforeunload でも状態保存。
- 建材リストで設定した採取数が、写真タブ→カメラ→戻る後に消えないように修正。

■ 仕上表
- 仕上表の初期表示を「内部」に変更。
- 外部/内部タブの順番を「内部 / 外部」に変更。

■ 建材リスト 操作パネル
- 操作パネル内の「統合」「削除」を折りたたみ式に変更。
- 初期状態では中身を閉じる。
- 開閉表示はシステム全体方針として「▶ / ▼」に寄せた。
- 統合/削除の実行ボタンは、対象選択まで押せないように調整。
- 誤操作防止のため、危険操作が常時見えっぱなしにならないUIへ変更。

■ 写真タブ 目視調査
- 目視写真ブロックの表示を整理。
- 内部は「床 / 巾木 / 壁 / 天井 / その他」の5ブロック固定。
- 外部は「床 / 犬走 / 外壁 / 屋根 / 軒裏 / その他」の6ブロック固定。
- 仕上表に入力がある部位だけ初期展開。
- 未入力部位は初期折りたたみ。
- 入力あり部位は薄色で強調。
- その他欄に入力された「配管」「窓枠」などは、写真タブでは「その他」ブロック内にまとめて表示。
- 写真枠の重複表示を修正。
- 右上の「入力あり / 写真枠」集計表示を削除。
- 「しまう」ボタンを削除し、開閉は「▶ / ▼」または行クリックに統一。
- 閉じている行でも、部位名 / 入力状態 / 写真枚数の位置が大きくずれないように調整。

■ 写真タブ 左リスト
- 外部グループの開閉トグルは維持。
- 内部という親見出しは削除。
- 内部側は「1階」「2階」など階数グループだけで表示。
- 左リストの目視写真枚数は、初期ダミーを含めず実写真のみカウントする方針に調整。

■ UIルール整理
- 開閉：▶ / ▼
- 追加：＋
- 実行：統合 / 削除 / カメラ起動などの文言ボタン
- 削除は赤系、統合は青系、上書きはオレンジ系の方針。
