# 調査システムPWA プロトタイプ v1.0.0

## 更新内容
- 建材リストを一覧表型で実装
- 仕上表 → 建材レコード → 建材リストの流れを追加
- 部位・建材使用箇所を仕上表から建材ID単位で集計
- 建材No.は有効建材の表示順として1から採番
- 建材IDは内部保持の固定IDとして扱う
- レベル、分析の要否、調査備考、採取数、採取場所1〜3、採取部位、採取チェック、採取日を追加
- 建材統合と削除のプロトタイプ操作を追加
- 統合時は仕上表セルを統合先へ置換し、調査備考を「、」で結合
- 統合/削除後は有効建材の名称末尾英字を詰める

## 更新方法
`app.html` と `version.json` を差し替えて push してください。
GitHub Actions方式の公開ファイル `.github/workflows/pages.yml` と `.nojekyll` は既存のままでOKです。
