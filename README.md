# 調査システムPWA v0.11.0 camera review

## 変更点
- v0.10.9をベースに、調査カメラを `camera.html` として同梱
- 写真タブに「カメラ起動」「看板カメラ」「採取カメラ」ボタンを追加
- 起動時に案件名・部屋No.などをURLパラメータでカメラへ渡す
- カメラ側で件名・住所・部屋No.を初期反映
- 撮影写真のIndexedDB保存データに、調査システム連携用のメタ情報を追加
- CSS/Service Worker衝突を避けるため、今回はカメラを別画面起動として仮組み込み

## 確認ポイント
- 写真タブから camera.html が開くか
- 件名に「ODKワールドアスベスト調査」が入るか
- 選択中の部屋No.が看板に入るか
- 採取カメラでサンプリング看板に切り替わるか
- 左上の「調査システム」ボタンで戻れるか
