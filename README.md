# 調査システムPWA プロトタイプ v0.10.9

## v0.10.9 修正内容
- 建材リスト上部の操作バーを仕上表側のデザインに寄せて調整
- 建材リスト上部に件数表示を追加
  - 採取
  - みなし
  - 目視等
  - 未設定
- 建材リスト上部にカラー表示ON/OFFを追加
- 建材リスト右端列を「No. / 部位 / 建材名」の確認表示に変更
- 建材リストの No. / ID 列幅を35pxに調整
- 建材リストの表記を「建材No.」→「No.」、「入力ID」→「ID」に変更
- 建材リストの部位列幅を縮小
- 建材名称、建材使用箇所、調査備考の長文表示を折り返し寄りに調整
- 統合/削除UIを操作パネル内に整理
- 統合先、統合する建材、削除する建材を「選択する」ボタンから選ぶ方式に変更
- 選択済み建材はチップ表示に変更
- チップを押すと選択解除できるように調整
- 統合先に選んだ建材は、統合する建材候補から除外
- 削除候補は、仕上表で未使用の建材を先に表示
- 仕上表で使用中の建材を削除する場合は確認ポップアップを表示
- レビュー用に仕上塗材A〜Eのサンプルを追加
