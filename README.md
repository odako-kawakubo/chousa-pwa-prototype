# 調査システムPWA Prototype v0.11.1

## 主な変更点

- 写真タブに目視調査 / 建材採取の切替を追加
- 目視調査は仕上表の入力セルに対応した写真枠を表示
- 建材採取は建材単位の左リスト、右側に採取箇所ブロックを表示
- 採取箇所ごとに採取前 / 採取中 / 採取後 / 断面のサムネ枠を横並び表示
- 目視/採取のサムネを選択可能に変更
- 複数枚は枚数バッジ表示
- 代表写真選択UI、ダブルクリック拡大プレビューUIを追加
- 目視/採取の左リスト選択後もスクロール位置を保持
- カメラを camera.html として仮組み込み
- サムネの「次回」表示が選択状態に見えないよう調整
